## §23 — Personalization Engine

> Ini salah satu **moat terbesar**.

```
Global Trends
      ↓
User Profile
      ↓
Behavior History
      ↓
Preferences
      ↓
Current Context
      ↓
Recommendation
```

Semakin lama digunakan:

```
Generic AI
    ↓
Personal AI
    ↓
Personal Digital Twin
```

## §24 — Recommendation Feedback Loop

> AI harus **belajar dari pilihan pengguna**.

```
Recommendation
      ↓
User Choice
      ↓
User Feedback
      ↓
Outcome
      ↓
Evaluation
      ↓
Preference Update
```

Contoh:

| | |
|---|---|
| AI merekomendasikan | Outfit A |
| User memilih | Outfit B |
| AI belajar | Preference(B) ↑ · Preference(A) ↓ |

> ⚠️ **Tetapi jangan menganggap satu pilihan sebagai perubahan permanen.**
> Gunakan **confidence + repeated behavior**.
