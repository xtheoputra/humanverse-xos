## Jenis Memory

| Memory | Contoh |
|---|---|
| **Working** | Chat aktif |
| **Short** | Hari ini |
| **Episodic** | Meeting kemarin |
| **Semantic** | Suka minimalis |
| **Procedural** | Cara workout |
| **Behavioral** | Tidur malam |
| **Emotional** | Mood turun |
