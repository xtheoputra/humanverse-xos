## Tujuh paket

| Paket | Fitur |

```
  Free       →  Habit, Mood
    │
  Plus       →  AI Coach
    │
  Pro        →  Fashion AI, Career AI
    │
  Elite      →  Digital Twin
    │
  Team       →  Family
    │
  Enterprise →  Company Wellness
```

Fitur paling mahal untuk dijalankan (**Digital Twin**) diletakkan di tingkat
paling tinggi — Elite.
