## §8 — Goal Intelligence

> User tidak hanya membuat habit. User membuat **GOAL**.

Contoh: *"Saya ingin menjadi AI Engineer."*

Goal dipecah:

```
AI Engineer
│
├── Python
├── Mathematics
├── ML
├── Deep Learning
├── LLM
├── MLOps
└── Projects
```

Kemudian:

```
Goal
 ↓
Milestones
 ↓
Projects
 ↓
Habits
 ↓
Daily Actions
```

> Ini penting. Karena **habit harus melayani tujuan, bukan sebaliknya.**
