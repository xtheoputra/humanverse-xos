> Berkas ini merekam kata pemilik apa adanya. Koreksi dan keraguan ada di

---

Memory dibagi menjadi beberapa jenis.

| Memory | Fungsi |
|---|---|
| **Working** | Percakapan aktif |
| **Episodic** | Kejadian |
| **Semantic** | Fakta |
| **Behavioral** | Pola |
| **Emotional** | Mood |

---

User berkata:

> "Saya suka pakaian minimalis."

```
  Fashion Preference Memory
```
