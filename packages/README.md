# `packages/`

Pustaka bersama yang dipakai lebih dari satu aplikasi
([`arch/03`](../arch/03-MONOREPO-FINAL.md) §3): `domain/ contracts/ events/ ai/
common/`.

⚠️ **Kosong di V0, dengan sengaja.** Dengan satu aplikasi (`apps/api`), belum
ada yang "bersama". Kode naik ke sini ketika aplikasi **kedua** membutuhkannya —
bukan sebelumnya, sebab pustaka bersama yang ditulis untuk satu pemakai
mengunci tebakan tentang pemakai kedua.
